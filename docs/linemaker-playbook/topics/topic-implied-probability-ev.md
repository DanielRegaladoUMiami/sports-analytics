# Tema: implied-probability-ev

Probabilidad implícita contra “probabilidad real”. El concepto está bien, pero se equivoca a menudo: −200 lo da como 60% o 80% (es 66.7%), confunde el gap de probabilidad con el EV y trata muestras chicas como el 100%.
